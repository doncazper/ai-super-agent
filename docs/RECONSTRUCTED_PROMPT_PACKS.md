# Reconstructed Prompt Packs

This archive exists so future Codex runs can understand historical feature tracks even when the exact original prompts are unavailable.

Rules:

- Reconstructed packs are not exact originals unless `exact_original: true` and source evidence proves it.
- Reconstructed packs must not be auto-queued or auto-run.
- Use original prompt packs under `prompts/packs/` when they exist.
- Reconstructed packs are planning/provenance artifacts, not execution authority.
