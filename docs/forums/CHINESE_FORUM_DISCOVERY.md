# Chinese Forum Discovery

Status: local tested v1; live use requires an approved configured search provider and safe public URL availability.

## Commands

```bash
python smart_agent.py cn-forums providers
python smart_agent.py cn-forums search "topic"
python smart_agent.py cn-forums search "topic" --sites zhihu,v2ex,tieba
python smart_agent.py cn-forums fetch "<url>"
python smart_agent.py cn-forums research "topic" --translate-to en
```

All commands execute through ToolBroker as `cn_forums.*` capabilities. Outputs are labeled `UNTRUSTED_WEB`, write no memory by default, and do not persist search history.

## Provider Approach

The v1 discovery layer uses approved web search providers with site filters:

- `zhihu`: `site:zhihu.com`
- `baidu_tieba` / `tieba`: `site:tieba.baidu.com`
- `douban_groups`: `site:douban.com/group`
- `xiaohongshu`: `site:xiaohongshu.com`
- `weibo`: `site:weibo.com`
- `v2ex`: `site:v2ex.com`
- `nga`: `site:bbs.nga.cn`

V2EX also has a documented read-only API connector. Non-V2EX Chinese platforms remain discovery-only unless a future official API connector is separately approved.

## Access Policy

- Use configured approved search providers only.
- Do not scrape platform search pages or result pages.
- Do not use login cookies, browser sessions, or platform-specific automation.
- Do not bypass CAPTCHA, anti-bot systems, login walls, robots policy, or blocked pages.
- Direct fetch is selected public URL only and uses the safe web fetch policy.
- Login-required, CAPTCHA-protected, anti-bot-protected, blocked, private, or unsupported pages return `unavailable`.
- Translation is optional and local-model generated by default; generated translations are labeled `MODEL_GENERATED_TRANSLATION`.
- No paid provider is used by default.
- No forum content, query history, or translations are written to memory by default.

## Source Grounding

Search results are snippet-only discovery signals until fetched. Fetched pages are still anecdotal forum/web evidence and must not be treated as authoritative, statistically representative, or cultural consensus.

Every source includes a stable `source_id`, URL, provider, retrieval timestamp when available, evidence type, and trust label. Fetch failures are reported separately and are not cited as source support.

## Limitations

Live quality depends on a configured search provider such as self-hosted SearXNG. Some Chinese platforms frequently require login, JavaScript, CAPTCHA, or anti-bot checks; v1 reports those pages unavailable instead of attempting bypasses.
