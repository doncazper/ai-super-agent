# Media License Policy

Status: specified only.
Last updated: 2026-05-25.

## Rules

- Do not claim commercial-use rights unless license evidence is tracked.
- Do not assume open weights mean unrestricted output use.
- Do not hide provider or model restrictions.
- Do not use paid/cloud providers by default.
- Do not generate content in the style of a living artist, brand, or copyrighted franchise without a future policy review.
- Do not use generated outputs for upload/publishing workflows in this track.

## Required License Evidence

Future provider records must link to or record:

- model license
- provider terms
- commercial-use status
- attribution requirements
- disallowed use notes
- training data caveats where known
- output ownership caveats where known

## Output Labels

Future generated assets must carry metadata such as:

- `generated_by_agent=true`
- provider id
- model id when known
- generated_at
- license status
- commercial_use_status
- source prompt hash or redacted prompt summary
- safety check result
