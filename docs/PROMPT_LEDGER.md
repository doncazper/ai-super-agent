# Prompt Ledger

This file tracks Codex prompt batches so future runs can tell what was run, skipped, failed, superseded, or still queued. It is best-effort and reconstructed from the current repo docs, tests, changelog, feature registry, feature maturity tracker, and completion report.

Status values: `queued`, `active`, `completed`, `skipped`, `failed`, `superseded`, `blocked`, `approval_required`, `needs_review`.

## Required Prompt Record Fields

Each prompt file and future structured ledger row should include:

- `prompt_id`
- `title`
- `category`
- `status`
- `source`
- `created_at`
- `pasted_to_codex`
- `started_at`
- `completed_at`
- `branch`
- `commit_hash`
- `related_feature_ids`
- `related_files`
- `files_expected`
- `files_changed`
- `expected_outputs`
- `commands_expected`
- `commands_run`
- `tests_expected`
- `tests_run`
- `test_result`
- `docs_updated`
- `changelog_updated`
- `feature_registry_updated`
- `feature_maturity_updated`
- `command_registry_updated`
- `completion_report_updated`
- `evidence_links`
- `blockers`
- `next_prompt_id`
- `supersedes`
- `superseded_by`
- `notes`
